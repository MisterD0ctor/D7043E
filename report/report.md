### 3.3 Beat Extraction
- R-peak position: sample index of the reference beat annotation (`atr`) - no QRS detector.
- 320 samples (0.889 s) before, 192 samples (0.533 s) after; final input length 512.
- Beats whose window exceeds the record boundaries are dropped (counted in `record_stats.csv`).

### 3.4 Signal Preprocessing
Raw MLII (mV) -> band-pass 0.5-40 Hz (4th-order Butterworth, zero-phase, whole record) -> segmentation ->
per-window z-score -> clip to +-5 -> divide by 5 -> model input in [-1, 1]. **TODO:** justification per step
(note: zero-phase filtering is non-causal; a device would use a causal filter).
